# XCoder-0.5B (Malay)
XCoder ialah pembantu pengekodan kecil berjalan pada CPU dengan 0.5B parameter.
Ia menyokong Bahasa Melayu dan English.
Ia membantu dengan JavaScript, TypeScript, Node.js, HTML, CSS, PostgreSQL, MySQL.
Cara guna: jalankan XCoder-0.5B di LM Studio dengan CPU-only, TTL 5 minit auto-unload.
